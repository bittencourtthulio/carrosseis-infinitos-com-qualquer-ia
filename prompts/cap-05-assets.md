# Prompt 05: Assets visuais

Material do livro **Carrosséis Infinitos com Qualquer IA: Praticamente Sem Gastar Tokens**.

## Onde usar

Cole este prompt em: IA de imagem escolhida, usando o briefing preparado no projeto. Substitua os campos entre colchetes por seus dados.
O agente local pode usar uma ferramenta de imagem conectada ou preparar o briefing para você usar na ferramenta escolhida.

## Prompt completo

```
[COLE O BRIEFING QUE O PROMPT ANTERIOR GEROU PARA A CAPA]

Acrescente no final do meu prompt:
  - Formato 1080x1350 (proporção 4:5 do Instagram).
  - Estilo visual: [ESTILO, ex: minimalista, com tipografia
    geométrica, paleta verde EXPX #16A34A + creme #F5F1E9].
  - Sem texto corrido na imagem (o texto vai ser inserido
    depois pelo template).
  - Sem fotos de pessoas, sem logotipos de empresas reais,
    sem cara de banco de imagem.
  - Resultado final: alto contraste, legível em miniatura no
    feed, com espaço livre no centro para o título ser
    sobreposto.
```

## Como conferir a entrega

Confira a imagem gerada e salve o arquivo aprovado em 04-pngs/assets/.

A preparação e as correções com o agente usam o modelo escolhido. O lote determinístico deve rodar em Python sem chamadas a modelos. Usar o iniciador local evita abrir uma nova conversa apenas para repetir o lote.
